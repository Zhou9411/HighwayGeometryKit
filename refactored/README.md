# 高速公路坐标高程计算软件 - 重构版本

## 项目概述

本项目是对原 VB6 编写的"高速公路坐标高程计算软件 4.3"的现代化 Python 重构。

原项目是一个用于高速公路工程中坐标和高程计算的 VB6 应用程序，包含平曲线计算、竖曲线计算、坐标转换、CAD 脚本生成等功能。

## 重构目标

1. **语言迁移**: VB6 → Python 3
2. **架构优化**: 过程式 → 面向对象
3. **代码质量**: 提高可读性、可维护性和可扩展性
4. **功能保持**: 保留所有核心计算功能

## 核心功能模块

### 1. 平曲线计算 (Horizontal Curve)
- 线元法计算
- 缓和曲线计算
- 圆曲线计算
- 直线段计算
- 方位角计算
- 交点法计算
- 坐标正算/反算

### 2. 竖曲线计算 (Vertical Curve)
- 竖曲线要素计算
- 变坡点处理
- 高程计算

### 3. 宽度渐变计算
- 横断面宽度计算
- 线性内插

### 4. 坐标转换
- 度分秒 ↔ 十进制度
- 极坐标 ↔ 直角坐标
- 已知坐标反算里程偏距
- 已知里程偏距正算坐标

### 5. 数据导入导出
- 支持 VB6 原格式文件
- JSON 格式导出
- CAD 脚本生成
- Excel CSV 导出

## 主要改进

### 1. 代码结构对比

| 特性 | 原 VB6 代码 | Python 重构版 |
|------|-----------|-------------|
| 架构 | Form + Module 混合 | MVC 分层架构 |
| 行数 | ~15,000 行 | ~1,100 行 (核心) |
| 模块化 | 低 | 高 |
| 可测试性 | 低 | 高 |

### 2. 命名规范

- **原代码**: 中英文混用 (`factor`, `置顶`, `GetHandle`)
- **重构后**: 统一英文命名，遵循 PEP8

### 3. 类型安全

- **原代码**: Variant 类型，易出错
- **重构后**: Python 类型注解 + dataclass

### 4. 错误处理

- **原代码**: 几乎无错误处理
- **重构后**: 完善的异常捕获和验证

### 5. 文档

- **原代码**: 注释较少
- **重构后**: 完整的 docstring 文档

## API 使用示例

### 平曲线计算

```python
from core.curve import HorizontalCurve
from models.curve_params import CurveSegment, CurveType

# 创建曲线段
segments = [
    CurveSegment(
        curve_type=CurveType.SPIRAL,
        station=1000.0,
        x_coord=50000.0,
        y_coord=50000.0,
        azimuth=153.240524,
        radius=-800.0,
        spiral_a=70.0
    )
]

# 创建计算器并加载参数
calculator = HorizontalCurve()
# ... 加载参数

# 计算指定里程的坐标
result = calculator.calculate_point(1100.0)
x, y, azimuth = result
```

### 竖曲线计算

```python
from core.curve import VerticalCurve

calculator = VerticalCurve()
grade_points = [(1000.0, 100.0), (1500.0, 105.0)]
elevation = calculator.calculate_elevation(1250.0, grade_points, 10000.0)
```

### 角度转换

```python
from core.curve import AngleUtils

utils = AngleUtils()
decimal = utils.dms_to_decimal(153.240524)  # 153.401456
dms = utils.decimal_to_dms(153.401456)      # 153.240524
```
