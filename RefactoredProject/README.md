# 高速公路坐标高程计算软件 - VB6 重构版

## 项目概述

本项目是对原有 Visual Basic 6.0"高速公路坐标高程计算软件"的规范化、现代化重构。

**原版本**: 4.3  
**重构版本**: 4.3 (重构版)  
**开发公司**: 双心软件有限公司  
**联系 QQ**: 43308724

## 重构目标

1. **代码规范化**: 统一命名规范、添加详细注释、分离关注点
2. **模块化设计**: 将功能按职责拆分为独立模块
3. **可维护性**: 提高代码可读性，便于后续维护和扩展
4. **保持兼容**: 完全兼容 VB6 运行环境

## 项目结构

```
RefactoredProject/
├── HighwayCalculator.vbp      # 项目文件
├── modConstants.bas           # 常量定义模块
├── modMathUtils.bas           # 数学计算工具模块
├── modAPIDeclarations.bas     # Windows API 声明模块
├── modKeyboardInput.bas       # 键盘输入模拟模块
├── HighwayCalculator.bas      # 核心计算模块
└── fraMain.frm                # 主窗体 (待重构)
```

## 模块说明

### 1. modConstants.bas - 常量定义模块
- 数学常量 (PI、角度转换等)
- 计算模式常量
- 曲线类型常量
- 错误代码定义
- 应用程序信息

### 2. modMathUtils.bas - 数学计算工具模块
- 角度转换函数 (度分秒↔弧度)
- 方位角计算
- 距离计算
- 坐标转换 (极坐标↔直角坐标)
- 反三角函数 (ArcCos, ArcSin)
- 数值舍入函数

### 3. modAPIDeclarations.bas - Windows API 声明模块
- 窗口查找与操作 API
- 窗口消息相关 API
- 线程与输入法相关 API
- 键盘状态相关 API
- 常量定义
- 封装函数 (置顶、GetHandle 等)

### 4. modKeyboardInput.bas - 键盘输入模拟模块
- SendInput API 封装
- 单键发送 (MySendKey)
- 文本发送 (MySendKeyText)
- 组合键发送 (Ctrl+X, Alt+X, Shift+X)
- 分步按键控制

### 5. HighwayCalculator.bas - 核心计算模块
- 曲线元素数据结构
- 竖曲线数据结构
- 横断面数据结构
- 缓和曲线坐标计算
- 圆曲线坐标计算
- 竖曲线高程计算
- 宽度渐变计算
- 曲线元素查找

## 代码规范

### 命名约定
- **模块前缀**: 
  - `mod` - 标准模块
  - `frm` - 窗体
  - `cls` - 类模块
- **变量命名**:
  - `lng` - Long 类型
  - `int` - Integer 类型
  - `dbl` - Double 类型
  - `str` - String 类型
  - `bln` - Boolean 类型
- **常量**: 全大写字母，下划线分隔 (如 `MAX_COUNT`)
- **函数/子程序**: 使用有意义的英文名称，首字母大写

### 注释规范
- 每个模块开头必须有模块说明头
- 每个公共函数/子程序必须有功能说明
- 复杂算法必须添加行内注释
- 使用中文注释以提高可读性

### 错误处理
- 使用 Err.Raise 抛出标准错误
- 定义统一的错误代码常量
- 关键计算必须进行参数验证

## 使用方法

1. 使用 Visual Basic 6.0 打开 `HighwayCalculator.vbp`
2. 编译生成可执行文件
3. 运行程序进行坐标高程计算

## 主要功能

- **线元法计算**: 基于线元法的平面坐标计算
- **缓和曲线**: 缓和曲线要素及坐标计算
- **直线计算**: 直线段坐标计算
- **方位角计算**: 两点间方位角计算
- **竖曲线计算**: 竖曲线高程计算
- **交点法**: 交点法平曲线计算
- **宽度渐变**: 超高渐变段宽度计算
- **横断面**: 横断面图生成

## 技术特点

1. **纯 VB6 实现**: 不依赖第三方组件 (除系统 OCX)
2. **高精度计算**: 使用 Decimal 类型保证计算精度
3. **API 封装**: 统一的 API 调用接口
4. **模块化**: 清晰的模块划分，便于维护

## 注意事项

- 需要 Visual Basic 6.0 运行环境
- 需要 MSVBVM60.DLL 支持
- COMDLG32.OCX 和 TABCTL32.OCX 需注册
- 仅支持 Windows 32 位系统
